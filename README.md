# FINANIHAN Supabase-ready
This version uses Supabase Auth and the database schema created in SQL Editor.
1. Keep your Supabase project configured.
2. Run the SQL schema from the previous step.
3. Serve the folder through a local web server (not file://), then open index.html.
4. Email OTP works when Email Auth is enabled.
5. Mobile OTP requires Supabase Phone Auth plus an SMS provider.
6. For production, add Row Level Security (RLS) policies before public deployment.
