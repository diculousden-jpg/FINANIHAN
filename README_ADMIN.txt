FINANIHAN ADMIN SETUP

1. Buksan ang admin.html.
2. Sa file na admin.html, hanapin:
   const ADMIN_EMAIL = "ILAGAY-DITO-ANG-ADMIN-EMAIL";
3. Palitan ang placeholder ng email na gagamitin mo bilang Admin.
4. Ang password ay HUWAG ilagay sa code. Gamitin ang password ng Supabase account na iyon.
5. I-upload ang updated files sa GitHub repository.
6. Admin Login page: /FINANIHAN/admin.html

Tandaan: Ang tunay na database authorization ay dapat ding protektahan gamit ang Supabase RLS kung gagamitin na sa production.
